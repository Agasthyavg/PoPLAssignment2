## Inorder helper

> Implement only an inorder traversal helper returning a list: left subtree, node, right subtree. Use an accumulator/tail argument if useful and avoid prohibited built-ins. Check `()` and `(4 (2 () ()) (6 () ()))` yielding `()` and `(2 4 6)`.

## Preorder helper

> Implement only a preorder traversal helper returning a list: node, left, right. Respect the shared constraints. Check `()` and `(4 (2 () ()) (6 () ()))` yielding `()` and `(4 2 6)`.

## Postorder helper

> Implement only a postorder traversal helper returning a list: left, right, node. Respect the shared constraints. Check `()` and `(4 (2 () ()) (6 () ()))` yielding `()` and `(2 6 4)`.

## Height helper

> Implement only a height helper: the empty tree has height 0 and a node has height one plus the maximum child height. Check empty, single-node and three-node skewed trees.

## Leaf helper

> Implement only a leaf-count helper: a leaf is a node with both children empty, and the empty tree has no leaves. Check an empty tree, a single node and a node with two leaf children.

## Print inorder

> Implement only `(print-inorder tree)` using the existing inorder helper. Display the list and exactly one trailing newline; the empty tree prints `()` on its own line.

## Print all traversals

> Implement only `(print-all-traversals tree)` using existing traversal helpers. Display inorder, preorder and postorder on three separate lines in that order, each ending in a newline, including three `()` lines for an empty tree.

## Print height and leaves

> Implement only `(print-height-and-leaves tree)` using the existing helpers. Display `(height leaf-count)` followed by a newline; check `(0 0)` for empty and `(1 1)` for a single node.
