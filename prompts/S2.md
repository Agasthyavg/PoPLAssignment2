## Shared context

Environment: Racket 8.x with `#lang racket/base`. Inputs are proper nested lists containing atoms and lists, with no dotted pairs. Use only the assignment's allowed forms and built-ins (`read` is also allowed for S2); no mutation, built-in `length`, `map`, `reverse`, or loops. Keep solution files definition-only and silent on load. Flat lists can contain 10,000 elements and nesting can reach depth 100.

For each unit below, use this shared context. Return only the requested definition or test file, followed by a concise explanation of its contract and the results of the specified checks. Distinguish checks actually run from checks proposed, and identify any assumption or unresolved ambiguity. Do not add top-level execution to a solution file or implement the whole problem in one response.

## Length helper

> Implement only `(my-length xs)` using tail recursion and the allowed built-ins. Count top-level items only: `()` has length 0 and `((1 2) () a)` has length 3. Avoid the built-in `length`.

## Reverse helper

> Implement only a tail-recursive reverse helper using allowed built-ins, without the built-in `reverse`. Check `()` and `(a b c)`.

## Map helper

> Implement only `(my-map f xs)` using the custom reverse helper and a tail-recursive accumulator to preserve order for 10,000 elements. Do not use built-in `map`; check empty and three-element inputs.

## Higher-order inserter

Measure each original list's top-level length with `my-length`, transform elements with `my-map`, and prepend `x` when `len-ok?` accepts that length. Never traverse newly inserted `x`. Check `((1 2) ())` with `x=7` and a length-less-than-2 predicate, and explain the empty-list result.

## Public function

> Implement only `(insert-if-short x lst n)` by calling `make-inserter` with a predicate testing length strictly less than `n`. Keep only one definition in the final file. Check empty input at `n=0` and `n=3`.

## Input and output

> Implement only `(print-insert-result)`: read `x`, `lst`, then `n` using `read`, display the insertion result, and end with one newline. Do not display a prompt or call it at top level.
